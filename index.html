Visão Geral

Do sinal bruto ao alerta para a equipe

Com a IA já integrada a exames, documentos e decisões clínicas (Fases 2 e 3), o hospital passa a monitorar continuamente os pacientes. Cada modalidade tem seu detector especializado; todos falam o mesmo "idioma" (Finding), o que permite fundir evidências e reconhecer quadros que nenhuma fonte isolada confirmaria.

🎥

Análise de Vídeo

YOLOv8-pose (layout OpenPose) para postura em fisioterapia e YOLOv8 para instrumental e áreas críticas em cirurgia, com relatório automático de desvios.

🎙️

Análise de Áudio

Biomarcadores de fadiga, disartria e dificuldade respiratória, eventos AudioSet, Azure Speech to Text e Text Analytics.

❤️

Detecção de Anomalias

Sinais vitais (NEWS2, z-score, CUSUM, Isolation Forest), prescrições e movimentação — em lote e em tempo real.

🧩

Fusão + Alertas

Risco fundido, síndromes multimodais (AVC, choque, queda...) e alertas P1/P2/P3 roteados, deduplicados e auditados.

Datasets

Os datasets sugeridos no enunciado, usados de verdade

DatasetUso no projeto
PhysioNet BIDMC (sugerido)53 registros reais de UTI (FC, SpO₂, FR a 1 Hz). 6 mapeados para pacientes — incl. SpO₂ real de 83% (BIDMC 32) e FC de 139 bpm (BIDMC 25); 47 treinam o Isolation Forest populacional.
Google AudioSet (sugerido)Ontologia de 632 classes + segmentos de avaliação → catálogo de 22 classes clínicas com mid oficial; classificador AST treinado no AudioSet confirma sons respiratórios.
ESC-508 gravações reais de tosse/respiração (o AudioSet não distribui áudio), escolhidas pelo próprio AST.
Sintéticos com ground truthConsultas em pt-BR (voz real sintetizada + perfis vocais), vídeos por modelo cinemático COCO-17, prescrições, actigrafia e PA — cada anomalia injetada é registrada e avaliada.
Modelos

Modelos aplicados em cada tipo de dado

🧍

Postura (fisioterapia)

YOLOv8n-pose → OpenPose COCO-18. ADM por repetição, assimetria bilateral, compensação de tronco, tremor 4–8 Hz e detecção de queda.

✂️

Cirurgia

YOLOv8 (ou pesos fine-tuned de instrumental): contagem início × fechamento, item retido na incisão, instrumento fora do campo, invasão de área estéril.

🗣️

Voz

F0, jitter, shimmer, HNR, taxa de fala, pausas, energia e tremor → scores de fadiga, disartria e respiratório. Tosse/respiração rotuladas com AudioSet + AST.

☁️

Azure

Speech to Text (pt-BR, WER), Sentiment Analysis, Key Phrases e Text Analytics for Health, com léxico clínico e negação para severidade.

📈

Sinais vitais

Regras NEWS2 com persistência, z-score robusto, CUSUM, Isolation Forest populacional e monitor online EWMA com rearme.

💊

Prescrições e movimentação

Farmacovigilância (alergia, dose, ISMP, duplicidade, suspensão) e actigrafia (queda, imobilidade, agitação noturna, Isolation Forest horário).

Nuvem

Integração com Azure Cognitive Services

☁️ REST puro, credenciais por variável de ambiente, fallback explícito

  • Speech to Text — transcrição pt-BR com confiança e WER contra a referência.
  • Text Analytics — sentimento (opinion mining), frases-chave e Text Analytics for Health (entidades clínicas com negação).
  • Entrega de alertas — webhook para Microsoft Teams / Azure Logic Apps.
  • Sem chave, o sistema usa fallbacks locais e informa o provider usado em cada resultado — nunca finge ser Azure.

Execução

Como rodar o projeto

# 1. dependências (suficientes para todo o pipeline, sem GPU e sem chave) pip install -r requirements.txt # opcional: YOLOv8 + AST (AudioSet) pip install -r requirements-ml.txt # 2. todos os pacientes e métricas python -m src.main run-all python -m src.main evaluate # 3. por modalidade python -m src.main video --patient-id PAC-0006 python -m src.main audio --patient-id PAC-0003 --audioset-model python -m src.main monitor --patient-id PAC-0004 --speed 20 # 4. painel da equipe médica (ou duplo clique em iniciar_painel.bat) python -m src.main serve --open # 5. testes python -m pytest -q # 40 passed
